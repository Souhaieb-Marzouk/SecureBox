# v1.0.2 — Per-app bypass and network controls

This update addresses the Android TV player reboot and adds the missing per-app network controls.

## Per-app VPN bypass

Some players and IPTV apps reboot the box while running inside a userspace VPN, even when browser and streaming apps work. Apps → app detail now has **Bypass SecureBox VPN**.

- The app is excluded with `addDisallowedApplication`; it uses the normal network.
- DNS filtering and the Local firewall **do not apply** to a bypassed app.
- The tunnel rebuilds automatically when the bypass list changes.
- Use it for VivoPlayer/IPsec/multicast-style apps that crash or reboot inside the tunnel.
- This is a workaround, not a fix for the underlying TV-box driver/kernel reboot.

## Block internet from the Apps tab

Apps → any app → **Network access** now has:

- **Block internet** — drops the app's TCP/UDP while the Local firewall is on.
- **Bypass SecureBox VPN** — excludes it from the tunnel.

The two controls are mutually exclusive: turning one on turns the other off. Blocked and bypassed apps show a badge in the Apps list.

## Open ports

- Port rows are now clickable and show protocol, port, UID, package and scope.
- **Block this app** is available when the port can be attributed to an installed package.
- Android does not allow closing another app's socket without root; blocking internet is the supported action.
- **UDP 68 is now hidden**: it is the normal DHCP client, not an internet-facing service.
- UDP 68 / TCP 14035 explanations remain in the port detail dialog where relevant.
