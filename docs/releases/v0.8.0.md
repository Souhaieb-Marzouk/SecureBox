# v0.8.0 — DNS Shield & Protection Stats

A one-switch DNS filter that needs no Private DNS setup, a cumulative protection-statistics page, and a TV remote-scroll fix.

## 📊 Protection statistics

- New **Protection statistics** page from the Privacy Shield hub.
- Cumulative counters: ads blocked, trackers blocked, pages cleaned of cookie/popup clutter, dangerous links blocked, and DNS queries blocked locally.
- Counters persist in the app's DataStore, update live, and can be reset.
- The DNS counter reports only what SecureBox blocked locally; the upstream resolver may filter more and does not report its counts.

## 🛡️ DNS Shield — no Private DNS needed

- New **DNS Shield** switch on **Privacy shield → Set up DNS**.
- Uses Android's one-time VPN permission, not Private DNS and not root.
- Creates a **DNS-only tunnel**: only the private DNS server address is routed into the VPN; all other app traffic bypasses SecureBox.
- DNS queries are checked against the local ad/tracker host list, then forwarded over **DNS-over-HTTPS** to the selected provider (AdGuard by default; Cloudflare for Families and Quad9 also available).
- No hostname to copy, no system Private DNS screen required — important for Android TV boxes where Private DNS is missing.
- One VPN at a time: the switch is disabled while the Local firewall is running.
- If Private DNS is set, Android may bypass DNS Shield; the screen warns and explains.

## 📺 Android TV scrolling fixed

The remote could not reach text-only areas above the first button or below the last one. Fixed with:

- Focusable card bodies and a focusable tail inside every `SecureCard`.
- Focusable top and bottom anchors in every scroll container.
- Focus stops for screen headings, status banners and settings sections.
- Applies to Network, Apps and the app-detail sheet, Settings, Dashboard, Threats, Hardening, Threat Intel, Privacy, Onboarding, Shield, DNS and Statistics.

D-pad can now land on text sections, scroll them into view, and return to the top.

## 🛠️ Technical changes

- New `DnsShieldVpnService` (core-data): DNS-only VPN, wire-format DNS parsing, local blocklist, DoH upstream, IP/UDP response construction and batched stats.
- Protected OkHttp socket factory so the shield's own DoH traffic never enters its tunnel; the DoH hostname is resolved before the VPN is established.
- New `ShieldStats`/`ShieldStatsRepository` persisted in DataStore.
- `DnsBlocklist` shared by the browser and the DNS service.
- AdGuard is now the default DNS preset (ads/trackers); Cloudflare for Families remains available for malware/adult filtering.
- New route `shield_stats`.
- 306 local Safe Browsing hash prefixes.

## ⚠️ Limits

- YouTube in-stream ads still cannot be removed by DNS or the embedded browser. YouTube serves them from the same video stream; SecureBox does not claim otherwise.
- HTTPS filtering inside other apps would require root or a MITM proxy.
- Apps that use their own DoH/DoT resolver can bypass any DNS filter.
- DNS Shield and the Local firewall cannot run together because Android permits one VPN.
- DNS Shield is new and needs physical TV/phone validation; if it does not capture queries on a particular firmware, turn it off and report the device.
