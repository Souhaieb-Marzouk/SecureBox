# v0.6.1 — Readability & TV Fixes

A focused follow-up to the Aurora redesign: readable text in dark theme, layouts that fit every phone and both languages, and a working Usage access action on Android TV.

## 🐞 Fixes

- **Dark-theme text is readable everywhere.** The theme now provides a default content colour (`onBackground`) and a default body text style, so text outside a card no longer falls back to black on the dark Aurora backdrop. Cards, action tiles and TV cards also set their content colour explicitly.
- **French and English fit their controls.** Navigation labels are short (`Accueil`, `Réseau`, `Applis`, `Menaces`, `Réglages`), app filters and network ranges scroll horizontally instead of overflowing, settings rows wrap long labels, the update button is shorter, and the dashboard gauge shrinks on very narrow phones.
- **Usage access opens on Android TV.** The old action only tried `ACTION_USAGE_ACCESS_SETTINGS`, which many boxes resolve to a blank/unrelated screen or fail to open. The app now detects TV, shows the exact manual path, and its “Open settings” button opens the TV's generic Settings app, which is always available. On phones it still opens the Usage access screen directly, with fallbacks to Settings and App info.

## 🛠️ Technical changes

- `SecureBoxTheme` now provides `LocalContentColor = onBackground` and `LocalTextStyle = bodyLarge`; `SecureCard`, `ActionCard`, `QuickTile`, `StatusBanner`, `TvActionCard` and `TvNavItem` set explicit content colours.
- App filters and network range chips use `LazyRow`; `RadioRow`/`PresetRow` labels use `weight(1f)` so they wrap instead of clipping.
- Phone bottom navigation labels are single-line with ellipsis, and French nav labels were shortened.
- Dashboard gauge adapts at `< 360 dp`; update button label shortened to “Check” / “Vérifier”.
- Network usage-access action resolves `USAGE_ACCESS_SETTINGS`, then `SETTINGS`, then `APPLICATION_DETAILS_SETTINGS`; TV users see a manual-path dialog whose action opens generic Settings.
- Apps list has a stable `apps_list` test tag because the filter row is now a second scrollable.
