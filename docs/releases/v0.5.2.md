# v0.5.2 — Clarity & Live Traffic

This release makes the Apps tab explain itself and gives you a direct path to fix what it finds. It also repairs the Live bandwidth list, and stops treating rooted TV boxes as tampered APKs.

## 🎯 Highlights

- **The Apps tab now explains its scores.** A short guide explains that 0 is the highest risk and 100 means no signals were found, with the full legend. Every row shows both the level and `score/100`.
- **Every finding is actionable.** Tapping an app now shows what the rating means, the risk signals behind it, the actual permissions requested (most sensitive first), and buttons that open the exact system screen: app settings, uninstall, accessibility, display-over-other-apps, usage access and device admin.
- **Live bandwidth works for every app.** Android's `TrafficStats` only exposes the calling app on modern versions, which is why Live showed only SecureBox. It now reads `NetworkStatsManager` for all UIDs, including Ethernet on TV boxes.
- **TV-box integrity warnings are accurate.** Root, test-keys and emulator signals are now advisory; only an APK signature mismatch locks updates. The card lists the specific signal and explains what it means.
- **The installed version is truthful.** The card reads the installed package through `PackageManager` and shows the build number, e.g. `Installed version 0.5.2 (build 9)`.

## 🛠️ Technical Changes

- Apps: added a “How to read this” card, risk legend, attention summary, two-line risk badge, plain-language meaning per level, a sensitive-first permission list with human labels, and system-settings intents.
- Network: `liveTotals()` now aggregates `NetworkStatsManager` from boot for Wi-Fi, mobile and Ethernet; the ViewModel's existing delta logic produces the live rate. Ports and anomaly cards gained explainers; ports gained a Rescan action.
- Integrity: `IntegrityIssue.TEST_KEYS` added; `compromised` is now only a signature mismatch; root/test-keys/emulator are advisory; the Settings card shows the correct advisory copy.
- Version: `AppVersion` is provided from `PackageManager`, with a BuildConfig fallback; the update card shows the installed build number.
- 3 new integrity tests (47 total).

## 🐞 Fixes

- Apps: “0 Critical” and “14 Critical” no longer appear without context; permissions are no longer just a count.
- Network: Live populated only SecureBox; it now lists all apps with traffic since boot.
- Network: Open ports and Upload anomalies now explain their purpose instead of showing unexplained text.
- TV box: “tampered or debugged” no longer appears for rooted/test-key firmware, and the version display reflects the actually installed package.

## 🔐 Security Notes

- SecureBox cannot revoke another app's permissions on Android. The new buttons open the system screens where the user can; the app says this explicitly instead of pretending to revoke.
- Root/test-keys being advisory does **not** weaken the update lock: a signature mismatch still blocks updates.
- Live traffic still runs entirely on-device through Android's own per-UID counters.
