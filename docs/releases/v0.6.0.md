# v0.6.0 — Aurora Redesign

A complete visual identity for phone and Android TV, built around a new 2.5D shield mark, a calm Aurora backdrop and plain-language actions anyone can follow.

![SecureBox 2.5D mark](https://raw.githubusercontent.com/Souhaieb-Marzouk/SecureBox/main/docs/branding/logo-1024.png)

## 🎨 A new identity

- **New 2.5D shield mark.** Teal-to-violet depth, a glossy face and an embossed check, generated reproducibly from one script (`tools/generate-brand-assets.py`).
- **New launcher icon** with a gradient adaptive background and a safe-zone foreground.
- **New Android TV banner** with the mark, wordmark and “PRIVATE. LOCAL. YOURS.” tagline.
- **New store icon** (512 px) in `docs/branding/`.

## ✨ Aurora design system

- **Deep-ink Aurora backdrop** with soft teal, violet and pink light pools on every screen.
- **Glass cards** with 24 dp corners, subtle gradient borders and depth.
- **Gradient accents**: electric teal `#35F2D0`, cyan `#22C7E8`, violet `#8B7CFF`, amber `#FFC46B`, coral `#FF6B81`.
- **New type scale** with heavier display headings and tighter letter spacing.
- **Gradient score ring** that changes colour with the grade, plus a soft glow.
- **Phone navigation** is now a floating glass bar with pill-highlighted icons; tablets use a slim rail.
- **Android TV** now has a translucent cinematic sidebar, large brand mark and the same Aurora backdrop.

## 🧭 Easier for everyone

- **Dashboard redesigned around four actions**: Scan apps, Block internet, Review apps, How to use. Each one says what it does in one sentence.
- **Score hero** states “You’re protected” or “A few things need attention” before showing the number.
- **“Needs attention” items** now explain why they matter and take you to the right screen.
- **New “How to use SecureBox” guide** on both phone and TV: four steps, a plain-language glossary (score, firewall, permission, sideloaded, tracker) and reassurance that nothing destructive happens without confirmation.
- The guide is reachable from the dashboard and from a prominent Settings card.

## 🛠️ Technical changes

- Added `AuroraBackground`, `BrandMark`, a redesigned `SecureCard`/`ScreenHeading`, gradient `ActionCard`, `StatusBanner` and `ScoreGauge`.
- Added the `HELP` route and `HelpScreen`; dashboard and settings both link to it.
- Added TV-aware sizing for the dashboard gauge and intrinsic-height quick tiles so text never clips at 10-foot sizes.
- Brand assets are generated from `tools/generate-brand-assets.py`; docs in `docs/BRANDING.md`.
- No changes to the VPN/firewall, scan engine, threat feed or update verification logic.

## 🐞 Fixes carried in this build

- Apps scores are explained, permissions are listed, and remediation opens system settings (v0.5.2).
- Network Live lists every app via `NetworkStatsManager`, including Ethernet (v0.5.2).
- Root/test-key TV firmware is advisory; only a signature mismatch locks updates (v0.5.2).

## 🔄 Update notes

- Installs over 0.5.2 with the same signing key; settings and scan data are preserved.

- If a TV launcher still shows the old banner, clear the launcher cache or reboot the box.
