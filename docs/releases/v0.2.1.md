# v0.2.1 — Issue Cleanup & Device QA Kit

A small patch on top of v0.2.0 that closes the backlog issues found after the release. No security model changed, no new permission, no data migration.

## 🎯 Highlights

- **The updater now shows what it is doing after the download finishes.** A "Checking the download" dialog appears while the SHA-256 checksum is compared, instead of an unexplained pause at 100 %.
- **A ready-to-run device QA helper.** `tools/device-qa.ps1` installs the APK on a connected phone or TV box, launches it, prints the version and resumed activity, and surfaces any crash — the fastest way to close the remaining device checks.
- **Smaller, cleaner build.** Unused test, icon and lifecycle libraries were removed from the version catalog and modules.
- **Play Store paperwork prepared.** `docs/PLAY_COMPLIANCE.md` contains the `QUERY_ALL_PACKAGES` declaration, the VPN disclosure and the data-safety answers.

## 🛠️ Technical Changes

- `UpdatePhase.Verifying` is now emitted by the repository through an `onVerifying` callback and rendered by a dedicated dialog (previously dead code).
- Removed unused dependencies: `mockk`, `kotlinx-coroutines-test`, `material-icons-extended`, `lifecycle-process`, `espresso-core`, and the app's unused test/androidTest dependencies; the version catalog was trimmed accordingly.
- Added `tools/sandbox-build.ps1` and `tools/sandbox-build-root.gradle` so restricted environments can build with outputs outside the checkout (`BUILDING.md`).
- Added `tools/device-qa.ps1` for on-device smoke checks.
- Backlog gained a real **Blocked** state (with its own filter and counter) instead of pretending hardware-dependent work is actionable.
- The `v0.1.0` and `v0.2.0` GitHub release titles now use the specified em dash.

## 🐞 Fixes

- Dead `Verifying` state replaced by a working checksum-verification step.
- Stale staging copy removed from the old workspace.
- CI now also runs the pure-Kotlin `core-domain` tests (28 tests), which `testDebugUnitTest` did not cover.
- Documentation for package visibility added to `PRIVACY.md`.

## 🔐 Security Notes

- No permission was added or removed in this patch.
- The update verification flow is unchanged: SHA-256 must match the published checksum, otherwise the file is deleted.
- The Play declarations do not change app behaviour; they document what already happens on-device.
