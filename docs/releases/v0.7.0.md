# v0.7.0 — Privacy Shield

A private browser, local ad/tracker/annoyance filtering, encrypted-DNS presets and local hash-prefix Safe Browsing.

## 🛡️ Privacy Shield hub

- New dashboard card and Settings entry.
- **Standard** tracking protection: blocks known ad/tracker hostnames and third-party cookies.
- **High** tracking protection: also strips tracking parameters from links and clears cookies when the browser closes.
- Toggles for ad/tracker blocking, cookie/popup hiding and Safe Browsing hash checks.
- Clear in-app explanation of what works system-wide and what does not.

## 🌐 Private browser

- Blocks requests to advertising and analytics hostnames before they leave the device.
- Hides common cookie-consent bars, social widgets, app-download banners and ad slots.
- Removes `utm_*`, `fbclid`, `gclid`, `msclkid` and similar parameters in High mode.
- HTTPS-only navigation, no file/content access, mixed content disabled, media autoplay requires a gesture.
- Live blocked-request counter; no history is uploaded.

## ☁️ DNS protection

- Presets with DoH endpoints and Private DNS (DoT) hostnames:
  - **AdGuard DNS** — ads and trackers system-wide.
  - **Cloudflare for Families** — malware and adult content.
  - **Quad9** — known malware/phishing domains.
- Shows the current Private DNS hostname, copies the selected hostname, and opens Android's Private DNS settings.
- Real DNS-over-HTTPS test with latency and resolved address.
- Explains that Android's system-wide encrypted DNS is DoT; DoH is used for the test.

## 🔎 Browsing security

- Checks navigations and subresources against a local **SHA-256 prefix** list.
- Only prefixes are bundled; full URLs are never stored or sent.
- List generated from the OpenPhish public feed plus Google's Safe Browsing test pages.
- WebView's platform Safe Browsing is also enabled.

## 🎨 Design

- New Privacy Shield hub in the Aurora style.
- Dashboard card for quick access.
- Settings card.
- Browser toolbar with HTTPS address bar, back/reload, and live shield count.
- DNS screen with resolver cards and step-by-step Private DNS instructions.

## ⚠️ Important limits

- **YouTube in-stream ads cannot be removed reliably** by DNS or an embedded browser. YouTube serves them from the same video stream; SecureBox does not claim otherwise.
- System-wide ad blocking works only at DNS level (AdGuard DNS preset) and only after the user applies Private DNS. It blocks ad/tracker domains, not every first-party ad.
- Filtering HTTPS inside other apps would require root or a MITM proxy; SecureBox does not do that.
- Cosmetic rules cover common cookie/popup patterns conservatively.

## 🛠️ Technical changes

- Added `TrackingProtectionMode`, `DnsPreset` and shield settings to `AppSettings`.
- Added `ShieldScreen`, `BrowserScreen`, `DnsProtectionScreen`, `ShieldViewModel`.
- Added `BrowserFilters`, `DohClient`, `SafeBrowsingStore` and `SafeBrowsingHash`.
- Bundled 300+ SHA-256 prefixes with no URLs.
- Added `ACCESS_NETWORK_STATE` to the settings module for Private DNS status.
- New routes: `shield`, `browser`, `dns_protection`.
